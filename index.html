Google Sheets Setup

Stock N' Scan can push your inventory to a Google Sheet on demand. Here's how:

  1. Open script.google.com and create a new project
  2. Delete existing code and paste the script below
  3. Replace YOUR_SHEET_ID with your Google Sheet's ID (from its URL)
  4. Click Deploy → New deployment
  5. Type: Web app · Execute as: Me · Access: Anyone
  6. Copy the Web app URL and paste it into Settings above
