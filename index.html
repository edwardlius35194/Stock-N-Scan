Firebase Setup

Set up a free Firebase project to sync inventory across devices in real time.

  1. Go to console.firebase.google.com
  2. Create a new project (skip Analytics)
  3. Click Realtime Database → Create database
  4. Start in test mode (you can secure it later)
  5. Copy the database URL — looks like:
    https://your-project-rtdb.firebaseio.com
  6. Go to Project Settings → General
  7. Under "Your apps" click </> Web, register app
  8. Copy the apiKey from the config shown
  9. Paste both values into Settings and tap Connect

Any device with the same URL + API key will share and sync the same inventory automatically.
